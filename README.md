# 🌾 Smart Crop Advisory & Farming Guidance Platform

## Project Description

This project helps farmers receive crop advisory, farming guidance, and expert recommendations through an online platform.

## Objectives

- Help farmers receive accurate farming guidance.
- Allow experts to publish crop advisory posts.
- Enable farmers to ask farming-related questions.
- Store data securely using MySQL.

## Technologies Used

- Java Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Git
